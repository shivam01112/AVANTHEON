Objective
This page should focus only on our three core solutions:
* Container Leasing
* Container Trading
* Lease-to-Own (our highlighted USP)

These do not have separate pages. Users should explore each solution through an interactive featured panel on the same page.

Page Structure

1.Hero Section

* Introduce all three solutions with a premium visual representing the complete solution ecosystem.

2.Interactive Solution Cards

* Three cards: Container Leasing, Container Trading, and Lease-to-Own.
* Lease-to-Own should be selected by default.
* Clicking any card should update the featured panel below without reloading the page.

3.Featured Panel

* Content changes dynamically based on the selected solution.
* Each solution should have:
* A unique image (avoid repeating container images)
* Short overview
* 3–5 key benefits
* CTA button (Request a Quote / Connect With an Advisor)
* Keep the content concise and impactful.

4.Interactive Comparison

* Compare all three solutions in one section.
* When a solution is selected, its column/card should automatically highlight so users can easily understand the differences.

5.Solution Finder

* A simple interactive section that helps users identify the most suitable solution based on their business needs and recommends the appropriate option.

6.Final CTA

* Encourage users to Request a Quote or Connect With an Advisor.

Interactions
* Smooth hover effects on solution cards.
* Clicking a solution should update the featured panel with smooth image and content transitions.
* The comparison section should respond dynamically to the selected solution.
* Use different visuals for each solution to avoid repetition.
* Maintain the same premium, enterprise-grade design language as the Home, About, and Industries pages.
